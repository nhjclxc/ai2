# 学习 LangChain 之前必须掌握的 Python 基础

这份文档只回答一个问题：

> 在学习 LangChain 之前，Python 至少要学到什么程度？

结论先说清楚：

你不需要先把 Python 所有高级特性学完，  
但必须掌握那些会直接影响 LangChain 学习和实战的基础能力。

如果这些基础不稳，学习 LangChain 时通常会出现几个典型问题：

1. 看得懂示例，自己写不出来
2. 知道要调用模型，但不会组织输入输出
3. 遇到报错时，不知道是 Python 问题还是 LangChain 问题
4. 会复制代码，但不会修改和扩展

所以这份路线不是“完整 Python 教程”，而是“学习 LangChain 之前必须打牢的 Python 最小必需集”。

---

# 学习目标

学完这份路线后，你应该能够：

1. 独立运行 Python 项目和虚拟环境
2. 看懂并修改 LangChain 官方示例代码
3. 编写函数、类和数据结构来组织 LLM 调用逻辑
4. 处理 JSON、文件、HTTP 请求和异常
5. 使用类型注解和 Pydantic 描述结构化数据
6. 理解同步、异步和流式处理的基本写法
7. 排查常见 Python 报错，而不是一报错就卡住

---

# 常见误区

---

## 误区 1：觉得学 LangChain 可以跳过 Python 基础

这是最常见的问题。  
框架只能放大已有能力，不能替代基础。

---

## 误区 2：只学语法，不写小程序

只看不写，进入 LangChain 示例后会立刻暴露问题。

---

## 误区 3：类和对象完全不学

LangChain 大量 API 都是对象形式，不会类就只能机械抄代码。

---

## 误区 4：忽略异常处理

模型调用、JSON 解析、工具调用、文件操作全都会失败。

---

## 误区 5：不会看 traceback

如果不会读 Python 报错，后面学习效率会非常低。
