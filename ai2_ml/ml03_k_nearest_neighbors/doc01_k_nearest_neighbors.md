# **一、KNN算法知识点详解**

## 1️⃣ 算法简介

* **中文名**：K近邻算法
* **英文名**：K-Nearest Neighbors (KNN)
* **类型**：监督学习

  * 可用于 **分类**（预测类别）
  * 可用于 **回归**（预测连续数值）
* **核心思想**：

> 给定一个待预测样本，找到训练集中距离它最近的 **K 个邻居**，根据这些邻居的标签来进行预测。

---

## 2️⃣ KNN工作原理

1. **训练阶段**：

* KNN 实际上不需要显式训练（称为懒惰学习，lazy learning）
* 保存训练集特征和标签即可

2. **预测阶段**：

* 计算待预测样本与训练集中所有样本的 **距离**
* 选择 **最近的 K 个样本**（邻居）
* 根据邻居的标签进行预测：

  * **分类**：多数表决（majority vote）
  * **回归**：取邻居标签的平均值或加权平均

---

## 3️⃣ 距离度量

常用的距离度量方法：

| 距离类型                | 公式                              | 特点         |             |                |
| ------------------- | ------------------------------- | ---------- | ----------- | -------------- |
| 欧氏距离 (Euclidean)    | ( \sqrt{\sum_i (x_i - y_i)^2} ) | 最常用，适合连续数值 |             |                |
| 曼哈顿距离 (Manhattan)   | ( \sum_i                        | x_i - y_i  | )           | 对异常值更稳健        |
| 闵可夫斯基距离 (Minkowski) | ( (\sum_i                       | x_i - y_i  | ^p)^{1/p} ) | p=1 曼哈顿，p=2 欧氏 |
| 闵式加权距离 (Weighted)   | 根据距离加权投票                        | 距离近的邻居权重更高 |             |                |

---

## 4️⃣ K 的选择

* K 太小 → 对噪声敏感（可能过拟合）
* K 太大 → 平滑过度（可能欠拟合）
* 常用经验：

  * K = √n（n为训练样本数）
  * 交叉验证选最优 K

---

## 5️⃣ 特点

### 优点

* 简单直观，容易理解
* 无需训练阶段，直接用训练集预测
* 可用于分类和回归

### 缺点

* **计算量大**：预测阶段需要计算所有训练样本距离
* **内存消耗大**：需要保存全部训练集
* 对 **特征尺度敏感**，需要归一化或标准化
* 对 **高维数据**表现较差（维度灾难）

---

## 6️⃣ 数据预处理建议

1. **归一化或标准化**

   * KNN 距离度量对尺度敏感
   * 常用方法：

     * Min-Max 归一化：([0,1])
     * Z-score 标准化：((x-\mu)/\sigma)

2. **处理缺失值**

   * KNN 对缺失值敏感，需要先填充或删除

# **二、KNN最简单示例（分类）**

使用 sklearn 库，最小可运行示例：

```python
from sklearn.neighbors import KNeighborsClassifier
import numpy as np

# 简单训练集（特征：x1,x2；标签：0/1）
X_train = np.array([[1,2], [2,3], [3,3], [6,5], [7,7], [8,6]])
y_train = np.array([0,0,0,1,1,1])

# 待预测样本
X_test = np.array([[3,2], [7,5]])

# 1. 创建 KNN 分类器，K=3
knn = KNeighborsClassifier(n_neighbors=3)

# 2. 训练（KNN其实是懒惰学习，但sklearn需要fit）
knn.fit(X_train, y_train)

# 3. 预测
y_pred = knn.predict(X_test)

print("预测结果:", y_pred)
```

### 输出示例

```
预测结果: [0 1]
```

解释：

* `[3,2]` 的三个最近邻：大部分是类别 0 → 预测 0
* `[7,5]` 的三个最近邻：大部分是类别 1 → 预测 1

# **三、总结**

| 知识点   | 说明                  |
| ----- | ------------------- |
| 类型    | 监督学习（分类/回归）         |
| 核心思想  | K 个最近邻决定预测结果        |
| K 的选择 | 小 K 对噪声敏感；大 K 可能欠拟合 |
| 距离度量  | 欧氏、曼哈顿、闵可夫斯基等       |
| 优点    | 简单、直观、可用于分类/回归      |
| 缺点    | 计算量大、内存大、对特征尺度敏感    |
| 预处理   | 特征归一化、缺失值处理         |
