# ai2
深度学习仓库2

[前置](https://github.com/nhjclxc/ai)

基础环境搭建
```shell
conda create -n ai2 python=3.10
conda activate ai2
# 安装机器学习常用包
conda install numpy pandas matplotlib scikit-learn jupyter
# 安装pytorch深度学习常用包
conda install pytorch torchvision torchaudio -c pytorch
```
